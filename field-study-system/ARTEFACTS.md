# The artefact library

Three kinds of thing go inside a page: a **chart** shows evidence, a **lever**
lets the reader change an assumption, an **interaction** is how they operate
either. Pick from this list rather than inventing per study.

Before adding anything, answer: what should the reader be able to *do* after
seeing it?

- Understand a quantity → a chart. No levers.
- Test whether the claim survives its own assumptions → an instrument. Needs
  levers, a baseline and a stated limit.
- Neither → cut it. An artefact that only demonstrates capability is the most
  expensive kind of filler.

## A · Charts

Every one carries its source and its unit. A chart with neither is decoration.

| Id | Chart | Rule |
| --- | --- | --- |
| A1 | Stat row | Three figures, never four. Count up on entry. The last carries the accent and makes the argument — often a zero. |
| A2 | Ranked bars | Ink for the series, accent for the row the claim is about. Absolute values on the right, tabular. Never a percentage alone. |
| A3 | Timeline spine | The licensed home for categorical hues, always with a legend directly above. Two threads is the useful number. |
| A4 | Coverage matrix | Two tint steps and empty. Never a continuous ramp — the reader should be able to count the filled cells. |
| A5 | Network | Accent for the node under discussion, petrol for the one being introduced, dashed for a relationship that does not exist yet. Never encode quantity in node size. |
| A6 | Log ledger | Once per study, where the point is that the technical part is not the slow part. A log scale must say so on itself. |

## B · Levers

A lever must change something visible without scrolling, and always show its
baseline.

| Id | Lever | Rule |
| --- | --- | --- |
| B1 | Slider | Mandatory: a baseline tick at the observed value, the delta beside the number, units. A slider with no baseline is a toy. |
| B2 | Either/or switch | For the study's central fork. Two options only — three is an archetype exhibit, not a switch. |
| B3 | Persona lens | Re-lenses a whole beat. One selection at a time; unselected actors stay visible so the reader knows whose view they left. |
| B4 | Scenario preset | A named bundle of lever positions. Three is the working number. |
| B5 | Depth control | Plain · Research · Technical, in the masthead, persisted per study. A lever on the prose, not the model — never in the drawer with the others. |

**Ceiling: five levers per instrument.** The drawer opens spine → peek → full;
peek lists only what has changed. Beyond five, a reader stops attributing the
change to their own action.

## C · Interactions

The same six verbs on every study, in the same places.

| Verb | Control | Rule |
| --- | --- | --- |
| Play | `▶ play` · `step` · `reset` | Anything staged gets all three, bottom-left, in that order. Never autoplay inside a beat — the reader is reading. |
| Inspect | hover/focus a mark → detail card | The card carries the same citation numeral as the prose. |
| Drill | every mark links to what produced it | A chart the reader cannot get behind is an assertion with axes. |
| Qualify | match-rate badge on the result | Any joined or modelled result states its confidence on the result itself, not in a caption. Unmatched records are shown dropping out. |
| Ask | `✦ ask the project` | Bottom-right on every beat, grounded in this study only, and it says so. Cites the same numerals. |
| Carry away | `share this state ↗` | Lever positions live in the URL. This is what makes an instrument usable in a meeting. |

## Motion

0.2s ease-out. The 1.5s live-dot pulse. Nothing else.
