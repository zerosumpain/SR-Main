# Ship gate

Run every line. Answer with the evidence, not "yes".

## Argument
- [ ] Three findings appear in the front matter, before beat 01.
- [ ] Every beat has exactly one question, printed at the top of the beat.
- [ ] Every beat has one claim that answers that question.
- [ ] Every beat ends with a "so what" in the author's voice.
- [ ] Every beat ends with an open question **and** a falsifier line.
- [ ] Beats are in the fixed order. None added.

## Honesty
- [ ] Every claim carries `fact` | `hypothesis` | `contested`. No other values.
- [ ] At least one `hypothesis` chip exists. (A study with none is not being
      honest about its own reasoning.)
- [ ] Every number carries a source and the date it was true.
- [ ] Estimated values are marked and excluded from every total.
- [ ] Every total reconciles to its rows. State the arithmetic.
- [ ] Every T4 risk column is at least as long as its benefit column.
- [ ] Every instrument states what it does not show, and where its numbers came from.
- [ ] Any joined or modelled result shows its match rate on the result itself.

## Design
- [ ] Every beat uses a template from `templates.json`. No bespoke layouts.
- [ ] No two consecutive beats share a template, except T1.
- [ ] Radii are 0, 2px or 100px only.
- [ ] No box-shadow inside a page.
- [ ] Categorical hues appear only in a legend and the marks it labels.
- [ ] Confidence chips are petrol / orange / claret — not categorical hues.
- [ ] Figures are numbered `Fig. n.m` with an italic serif caption.
- [ ] Text FILLS its column — no `ch` cap on any element. No two-column body
      text. To shorten a line, narrow the column, never the text.
- [ ] No emoji anywhere.

## Instruments
- [ ] No serif, drop caps, margin notes or pull quotes in a T5.
- [ ] No page scroll; HUDs are absolutely positioned and collapsible.
- [ ] Five levers maximum. Each shows its baseline.
- [ ] Lever positions are in the URL.
- [ ] No autoplay when embedded in a beat.

## Shell
- [ ] Depth control (Plain / Research / Technical) present and persisted.
- [ ] Every beat has Plain and Research text. Technical falls back to Research.
- [ ] Personal-capacity disclaimer on every page.
- [ ] Sources are reachable from the beat that cites them, not only the footer.
- [ ] Margin column collapses below 900px with notes falling inline.
